# Start with a deterministic traffic tracer-bullet slice

We will first implement a deterministic GraphNAMLSS tracer-bullet slice on METR-LA before expanding to the full 2x2x2 primary experiment matrix and later Bayesian graph-stream experiments. This keeps the first milestone focused on validating the traffic data pipeline, Gaussian location-scale likelihood, temporal split, metrics, and interpretability outputs before adding variational graph weights, structural uncertainty experiments, PEMS-BAY replication, and the Spatial Health Graph application track.
